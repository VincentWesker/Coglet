Servos & animations

Disconnected

Connect the RP2040 USB port separately from the ESP32 log console. Updated RP2040 firmware is required. Connecting does not request movement.

Movement can pinch fingers or strain linkages. Clear the mechanism and use its calibrated limits. Stop disables PWM, not servo power; unsupported parts may drop. Physical Calibration Mode always has priority.

Connect motion USB to load servo limits and available animations from the firmware.

Animation preview

Previews replace normal motion and pause face tracking. Expressions run until stopped; one-shot actions run for two seconds, then hold.

Normal behavior may move the robot. If a USB override loses its heartbeat for 5 seconds, PWM is disabled until you request motion again or physical calibration takes control.

Upload RP2040 Python files

Disconnected

Install local .py files through MicroPython's built-in USB REPL, including the first diagnostics update. MicroPython must already be installed; this does not flash UF2 or update the ESP32.

Prepare the board

Support the mechanism and disconnect the external 5 V servo supply. USB can power the logic. Connecting here interrupts the running program; motion Stop and heartbeat protection no longer apply in the REPL.

Set Programming Selector to RP2040 (lower), Calibration and Face Tracking OFF (right), and Main Power OFF (right). Leave BOOT and Servo Test released. Close Thonny and disconnect Logging and Motion first.

Disconnect Logging and Motion before opening firmware USB. Existing sessions will not be closed for you.

Connection remains disabled until this acknowledgement is selected.

Review files to replace

For this diagnostics update, choose animation.py, diagnostics_control.py, and main.py from CogletESP\RP2040. Keep the board's existing servoclass.py and vision.py unless intentionally updating them.

Root filenames only. UTF-8 source, up to 16 files, 96 KiB per file and 256 KiB total. Files stay local until you upload them to the selected RP2040.

    Prepare the board before connecting. Uploads check SHA-256 and Python syntax without running the selected files.
